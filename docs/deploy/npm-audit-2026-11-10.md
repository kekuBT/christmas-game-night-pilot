## Related deployment-readiness gap (not an advisory)
- `npm run serve` runs the server through `tsx`, which is a **development** dependency.
- A production install (`--omit=dev`) would therefore have no way to start the server.
- Before deployment, compile the server (`npm run build`, `tsc`) and run it with Node, or move `tsx` to `dependencies` deliberately.

## Proposed order (each its own tested change; none started)
1. **zod 4:** the only shipped, reachable advisory. Migrate the schemas, then run the full gate.
2. **The build tools:** move them to `devDependencies` (Vite, its React plugin, `@types/*`) so a production install doesn't carry them. Then upgrade Vite.
3. **Vitest:** upgrade to a fixed major, so the test runner is fixed.
4. **ESLint and typescript-eslint:** when a fixed release on the current major exists.
